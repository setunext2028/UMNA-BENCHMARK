# tools/audit.py and tools/lint_human.py

Developer: Koushik Das - Version 0.1.0

Both tools are done gates and exit non-zero on failure.

## tools/audit.py

### check(flag, success, failure=None)
Records a failure or prints the successful assertion. A check cannot pass
without evaluating a real condition.

### _tree(path)
Parses a Python file into an AST. Import and call-path checks use syntax,
not prose matching.

### _imports_name(path, name)
Returns true when an `import` or `from ... import ...` statement imports an
exact symbol name. Used to keep `Manifest` out of planner code.

### _imports_module(path, module)
Finds direct or nested imports of a package. Used for runtime/planner/Wing
dependency direction.

### check_manifest_allow_list()
Runs every on-disk Wing manifest through the actual strict loader. The audit
therefore cannot disagree with production parsing about nested fields.

### check_planner_reads_no_manifest()
Rejects a planner import of `Manifest`. Planner numbers must enter through
host-owned metrics.

### check_execute_has_no_rogue_callers()
AST-scans runtime, planner, risk, Wings, Core, and bench for a direct import
or call of `runtime.execute.run`. S1 has no serving caller; later serving
code must expose an admission-aware seam the audit can recognise.

### check_layer_boundaries()
Checks that runtime imports neither planner nor Wings, and planner imports
no Wing implementation.

### check_trace_terms()
Reads the `LatencyBreakdown` dataclass through AST and requires exactly the
eight terms in `docs/05_SEAMS_AND_API.md`.

### check_version_pinning()
Every package that declares `VERSION` must declare `0.1.0`.

### run_tests()
Runs unittest discovery in a subprocess. The environment marker prevents
the audit gate test from recursively starting another audit.

### main()
Runs all checks, exits one when any fail, otherwise prints the human review
reminders that cannot be automated.

## tools/lint_human.py

### Module setup
- Reads the forbidden vocabulary from `docs/09_HUMAN_CODE.md`; the policy
  document is the single source of truth.
- Exempts that one policy file and no other path.
- Compiles patterns for vocabulary, emoji, attribution trailers,
  changelog headers, and decorative banner comments.

### scan(path)
Reads one text file and records every violation with path and line number.

### line_no(text, offset)
Converts a regex byte/character offset to a one-based line number.

### main()
Scans every `.md`, `.py`, `.txt`, `.yaml`, and `.yml` file under the repo,
excluding only the policy file, `.git`, and generated bytecode directories.
Exits one on any violation.
